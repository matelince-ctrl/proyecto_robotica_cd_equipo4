# proyecto_robotica_cd_equipo4
Repositorio del proyecto de la estación 4 de una línea automatizada de ensamblaje de PCB. Incluye el desarrollo del manipulador SCARA PRR, la arquitectura ROS 2, planificación de movimiento con MoveIt 2, integración con ros2_control, firmware de la ESP32 y control de la cama caliente con celda Peltier.
